# Project Summary
The School Transport Management System is a mobile application designed to streamline transportation logistics for educational institutions. It facilitates communication between drivers, students, parents, and school administrators, enhancing safety and operational efficiency. Key features include real-time updates, optimized routing, and a notification system for class dismissals, making it indispensable for modern educational transport management.

# Project Module Description
The system includes the following functional modules:
1. **Driver Interface**: Allows drivers to log in, update their status, and receive notifications.
2. **Student Interface**: Enables students to select drivers and receive real-time updates.
3. **Admin Interface**: Empowers administrators to monitor drivers and manage logistics.
4. **User Registration**: Facilitates user registration with email or phone verification.
5. **Password Recovery**: Provides secure password reset functionality.
6. **Real-Time Synchronization**: Ensures instant updates of driver statuses.
7. **User Session Management**: Enhances security through session management.
8. **Profile Management**: Allows users to update their personal information.
9. **Driver Dashboard**: Enables drivers to manage their status and notifications.
10. **Cloud Storage Integration**: Utilizes Supabase for data management.
11. **Notification System**: Sends notifications to drivers regarding class dismissals.
12. **Admin Control Panel**: Offers administrative control over drivers and notifications.
13. **Super Admin Interface**: Provides comprehensive control over user accounts and system settings.
14. **Cloud Storage Status Indicator**: Displays the status of the cloud database connection in admin dashboards.
15. **Database Management**: Manages data schema for students, buses, routes, trips, attendance, and payments.

# File Description Inventory
- **src/components/**: UI components for registration, dashboards, password recovery, and notifications.
- **src/hooks/**: Custom React hooks for state management.
- **src/lib/**: Utility functions for cloud storage management and real-time synchronization.
- **src/pages/**: Page components for various application views, including login and dashboards.
- **src/types/**: Type definitions for users, notifications, schools, and class dismissal times.
- **src/lib/supabaseClient.ts**: Manages connection and operations with the Supabase cloud database.
- **src/lib/cloudStorage.ts**: Handles user data storage, including retrieval and management of system accounts and notifications.
- **src/components/CloudStorageStatus.tsx**: Displays the current status of the cloud database connection.
- **src/components/AdminDashboard.tsx**: Admin dashboard component, now includes CloudStorageStatus.
- **src/components/SuperAdminDashboard.tsx**: Super admin dashboard component, now includes CloudStorageStatus.
- **src/components/LoginForm.tsx**: User login form component.
- **install.sh**: Script for automatic installation of dependencies and project setup.
- **deploy.sh**: Script for automatic deployment of the application.
- **server.sh**: Script for setting up the server environment.
- **dist/**: Contains the built application files ready for deployment, including `index.html` and assets.
- **database-schema.sql**: SQL script for creating and managing the database schema for the transport management system.
- **NETLIFY_DEPLOYMENT_GUIDE.md**: Comprehensive guide for connecting the application to Supabase and deploying it on Netlify.

# Usage
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Lint the code:
   ```bash
   pnpm run lint
   ```
3. Build the application:
   ```bash
   pnpm run build
   ```
4. For the Android application:
   - Install Capacitor dependencies:
     ```bash
     npm install @capacitor/core @capacitor/cli @capacitor/android
     ```
   - Initialize the Capacitor project:
     ```bash
     npx cap init "School Transport" "com.schooltransport.app"
     ```
   - Add Android platform:
     ```bash
     npx cap add android
     ```
   - Sync changes:
     ```bash
     npx cap sync
     ```
   - Build the Android application:
     ```bash
     npx cap build android
     ```
5. Deploy to Vercel:
   ```bash
   npm install -g vercel
   vercel --prod
   ```
6. For automatic installation, run:
   ```bash
   ./install.sh
   ```
7. For deployment, run:
   ```bash
   ./deploy.sh
   ```
8. For server setup, run:
   ```bash
   sudo ./server.sh
   ```
